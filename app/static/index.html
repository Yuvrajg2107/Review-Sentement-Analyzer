READ THESE RESULTS WITH CONTEXT

Both models use IMDb sentiment data, but their training histories differ. Our model's hyperparameters are selected on a train-only validation split, then the selected baseline is refitted on the full official training partition. The pretrained model comes from an upstream training run; its model card does not provide all the details needed to reproduce an identical training procedure. Dataset identity matches, but identical upstream training rows cannot be independently guaranteed. This is a shared test-set comparison, not a controlled experiment in architecture alone. DistilBERT reads the first 512 tokens while TF-IDF reads the full review; this length policy can affect results.

Movie reviews are the intended domain. Product reviews, sarcasm, mixed opinions and unfamiliar wording can produce confident mistakes. Neither model has a neutral class.

01

Words carry weights.

TF-IDF gives a phrase more weight when it is frequent in a review but less common across the training set. Logistic Regression learns which weighted features support positive or negative sentiment.

02

Small patterns help.

The experiment compares word features alone with a word-and-character combination. Character n-grams capture parts of words; word bigrams capture phrases such as “not good.” Validation determines which representation is retained.

03

Tuning earns its place.

Regularization controls how strongly learned coefficients are penalized. Candidate settings are compared using validation data from the training partition. The test labels are reserved for the final evaluation.

WHAT MAKES THE BASELINE DIFFERENT?

The experiment tests word TF-IDF and a combined word-and-character representation, then selects the configuration and Logistic Regression regularization using validation F1. In the combined candidate, word features have weight 1.0 and character features have weight 0.5; those are feature-group multipliers, not class weights. Logarithmic term-frequency scaling reduces the influence of repeated words. These are established techniques, not a new algorithm. There are no hand-written sentiment overrides and no corrections based on the test answers. Any measured advantage must be read from the evaluation report.
